# Blackmagic API test with Qt 6.11 OpenAPI support

Sandbox for testing generation of usable QtQuick friendly library 
from OpenAPI yaml files from various Blackmagic Design devices.

Device currently "supported" are:

* Hyperdeck
* Camera
* Web presenter

## Requirements

* Qt 6.11 or later with OpenApiCommon and OpenApiTools installed.
* OpenAPI generator installed

Tested to build with version 7.26.0 OpenAPI generator, available from
https://openapi-generator.tech/docs/installation/

## Status

Not even remotely usable for anything more than testing at this time.
